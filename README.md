# Capstone Project - E-shop: Multi-page online store

## Overview

This repository contains a fully responsive, multi-page e-commerce website developed as a Capstone Project for EPAM Learning Fundamentals. The platform enables users to search, filter, and view products available for sale. The functionality for buying, reviewing and storing items in shopping cart is also implemented.

## Features

- **Responsive Design**: Fully optimized for all devices (mobile, tablet, desktop)
- **Sorting & Filtering**: Multiple options to refine property searches
- **Image Galleries**: High-quality product images
- **Product Details**: Comprehensive information about each product
- **Contact Forms**: Easy communication with e-commerce team
- **Shopping Cart**: Saving and managing all purchases

## Pages

- **Homepage**: Featured products in a carousel and highlighted categories
- **Catalog**: Filtering, sorting, and pagination features
- **About Us**: Page containing details about the company and its team members
- **Contact Us**: Page with a functional form
- **Product Details**: Detailed information about a selected product
- **Shopping Cart**: Page where users can add, update, or remove products

## Technologies

- **HTML5**: Semantic markup
- **SCSS**: Advanced styling with variables and mixins
- **JavaScript**: Interactive functionality

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:

```
git clone https://autocode.git.epam.com/klochkova.alex91/fundamentals-project-template
```

2. Navigate to the project directory:

```
cd fundamentals-project-template
```

3.  Install dependencies:

```
npm install
```

4. Compile SCSS files:

```
npm run compile
```

5.  Start the development server:

```
npm run dev
```

6.  View the website in your browser.[http://localhost:5173/](http://localhost:5173/)

### Linting

1.  Lint SCSS and JS files:

```
npm run lint
```
